# PLUG THE LEAKS

**The game is the audit.** A 60-second arcade game: customers walk to your shop, business-problem leaks open in their path — tap to plug them before customers fall through.

## The funnel

Play → feel your own leaks → end screen: "Your real business leaks customers the same way. Get a FREE leak check." → button to the free growth-plan lead capture.

## Run it

Open `index.html` in a phone browser. No login, no install.
